# Connections 页面增强：设备视图

## 目标

在 Connections 页面新增两个 Tab，展示连接的设备/客户端信息：
1. **活跃设备** — 当前正在使用代理的设备
2. **最近设备** — 近期断开的历史设备

综合视图包含：IP、设备状态、连接数、实时流量、历史记录。

---

## 设计方案

### 页面结构

```
Connections 页面
├── Tab 栏: [活跃连接] [活跃设备] [最近设备]
└── 内容区（根据 Tab 显示不同内容）
```

**Tab 说明：**
- **活跃连接**（默认）：现有的逐条连接列表，按 Mihomo 返回的原始数据显示
- **活跃设备**：按 sourceIP（客户端 IP）聚合的设备卡片，实时更新
- **最近设备**：历史断开设备，按 IP 聚合，带"最后活跃"时间戳

---

### 活跃设备 Tab

**数据来源：** Mihomo `/connections` API

**卡片布局（每设备一个卡片）：**

```
┌─────────────────────────────────────────────────────────┐
│ 📱 192.168.1.100                           [3 连接]    │
│ ↑ 1.2 MB/s  ↓ 5.6 MB/s                              ▼ │
├─────────────────────────────────────────────────────────┤
│ ├─ api.github.com:443       → vmess-hk-01    ↑128KB ↓2.1MB │
│ ├─ google.com:443           → DIRECT         ↑12KB  ↓45KB  │
│ └─ apple.com:443            → vmess-sg-02    ↑256KB ↓8.2MB │
└─────────────────────────────────────────────────────────┘
```

**字段说明：**
- `📱 设备IP` — sourceIP，Mihomo API 的 `metadata.sourceIP`
- `N 连接` — 该 IP 当前的活跃连接数
- `↑/↓ 速度` — 该设备所有连接的聚合实时流量（每 2 秒刷新时计算 delta）
- **可展开的连接明细**：每个连接的 destinationHost:port、使用的代理链、该连接的流量

**交互：**
- 点击卡片顶部可以展开/收起连接明细
- 设备按流量（总带宽）降序排列
- 无活跃设备时显示空状态

---

### 最近设备 Tab

**数据来源：** `settings.yaml` 中的 `closed_connections` 历史记录

**卡片布局：**

```
┌─────────────────────────────────────────────────────────┐
│ 📱 192.168.1.100                           [已断开]    │
│ 最后活跃: 2 分钟前                                     ▼ │
├─────────────────────────────────────────────────────────┤
│ ├─ 累计流量: ↑ 45.6 MB  ↓ 123.4 MB                    │
│ └─ 最后连接: api.github.com:443 → vmess-hk-01          │
└─────────────────────────────────────────────────────────┘
```

**字段说明：**
- `设备IP` — 从 connection_history 按 source_ip 聚合
- `已断开` — 状态标识
- `最后活跃` — 最近一条 connection 的 closed_at 时间
- `累计流量` — 该 IP 所有历史连接的流量总和
- `最后连接` — 最近断开的连接的目的地和代理链

**交互：**
- 同样可展开查看该设备的完整历史连接列表
- 按"最后活跃时间"降序排列

---

### 技术实现要点

**后端：**

1. **设备聚合 API**（可选，也可在前端聚合）：
   - `GET /api/connections/devices` — 返回聚合后的活跃设备列表
   - `GET /api/connections/history/devices` — 返回聚合后的历史设备列表
   - 或者复用现有 `/api/connections` 和 `/api/connections/history`，前端聚合

2. **速度计算**：
   - 前端每 2 秒轮询 `/api/connections`
   - 两次轮询之间的流量 delta 即为速度
   - 按 sourceIP 聚合

**前端：**

1. 在 Connections 页面 HTML 中添加 Tab 切换逻辑
2. 复用现有的 `api()` 函数获取数据
3. 复用现有的连接数据（`metadata.sourceIP`、`destination`、`chains`、`upload`、`download`）
4. 用 JavaScript 按 sourceIP 聚合实现设备视图

**UI 样式：**
- 设备卡片使用现有 `.card` 样式
- 连接明细使用 `.table` 结构
- 速度显示使用 `.mono` 字体
- 复用 Connections 页面的图标（上传/下载箭头）

## 验收标准

1. 活跃设备 Tab 显示所有当前连接的设备 IP，流量聚合正确
2. 最近设备 Tab 显示历史连接按 IP 聚合的结果
3. 切换 Tab 时正确清空上一个 Tab 的定时器
4. 无活跃设备/历史时显示友好的空状态
