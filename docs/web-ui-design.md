# Control Tower Web UI 设计文档

## 1. 功能总览

### 1.1 CLI 命令分类

| 分类 | 命令 | 功能描述 |
|------|------|----------|
| **服务** | `service start/stop/restart/status/logs` | 服务生命周期管理 |
| **代理** | `proxy list/select/test/stats` | 节点列表、选择、延迟测试、统计 |
| **模式** | `mode get/set tun-enable/disable` | 规则/全局/直连模式、TUN开关 |
| **订阅** | `profile list/add/remove/update/activate/cron` | 订阅管理 |
| **规则** | `rule list/add/remove/import/export` | 规则管理 |
| **连接** | `connections list/close/detail/top` | 连接查看、关闭、详情、实时监控 |
| **更新** | `update all/mihomo/geoip` | 更新核心和数据库 |
| **配置** | `config get/set` | 配置查看和修改 |

### 1.2 Web UI 对接映射

| Web 页面 | 对应 CLI | API 端点 |
|----------|----------|----------|
| 首页/仪表盘 | `service status` + `proxy stats` | `/api/service/status`, `/api/proxies` |
| 节点管理 | `proxy list/select/test` | `/api/proxies`, `/api/proxy/delay` |
| 订阅管理 | `profile list/add/remove/update/activate` | `/api/profiles/*` |
| 规则管理 | `rule list/add/remove/export` | `/api/rules` (需新增) |
| 连接监控 | `connections list/top` | `/api/connections` |
| 设置页 | `config get/set`, `update` | `/api/config`, `/api/update` |

## 2. Web UI 页面设计

### 2.1 设计风格

- **主题**: 深色专业风格，参考 V2RayN / Clash Verge
- **配色方案**:
  - 背景主色: `#1a1a2e` (深蓝黑)
  - 侧边栏: `#16213e` (深蓝)
  - 强调色: `#00d9ff` (科技青)
  - 成功色: `#00c853` (绿色)
  - 警告色: `#ff9800` (橙色)
  - 错误色: `#f44336` (红色)
  - 文字主色: `#e0e0e0`
  - 文字次色: `#9e9e9e`
- **字体**: `Inter, -apple-system, sans-serif`
- **布局**: 左侧固定导航栏 + 右侧内容区

### 2.2 页面结构

```
┌─────────────────────────────────────────────────────┐
│  Header: Logo + 服务状态指示灯 + 版本号             │
├──────────┬──────────────────────────────────────────┤
│          │                                          │
│  侧边栏   │           内容区域                       │
│          │                                          │
│  📊 首页  │   (根据选中页面动态渲染)                 │

│  📏 规则  │                                          │

│  ⚙️ 设置  │                                          │
│          │                                          │
└──────────┴──────────────────────────────────────────┘
```

### 2.3 各页面功能

#### 2.3.1 首页 / 仪表盘

**功能**:
- 显示服务运行状态 (运行中/已停止)
- 当前模式 (规则/全局/直连)
- 当前选中的代理节点
- 快捷操作按钮 (启动/停止服务、切换模式)
- 流量统计 (总上行/下行)
- 在线节点数 / 总节点数

**布局建议**:
```
┌─────────────┬─────────────┬─────────────┐
│  状态卡片    │  模式卡片    │  节点卡片   │
│  ● 运行中   │  规则模式    │  香港 101   │
└─────────────┴─────────────┴─────────────┘
┌─────────────────────────────────────────┐
│  快捷操作                                │
│  [启动服务] [切换全局] [切换规则]         │
└─────────────────────────────────────────┘
```

#### 2.3.2 节点管理页

**功能**:
- 左侧: 代理组树形列表 (GLOBAL, 自动选择等)
- 右侧: 当前组内节点列表
  - 节点名称
  - 延迟 (带颜色指示: 绿<100ms, 黄<500ms, 红>500ms)
  - 点击节点可切换
  - 支持搜索/过滤
- 批量测速按钮
- 当前选中的节点高亮显示

**交互**:
- 点击节点 → 切换并显示成功提示
- 点击测速按钮 → 显示所有节点延迟列表
- 搜索框 → 实时过滤节点

#### 2.3.3 订阅管理页

**功能**:
- 订阅列表表格
  - 名称 | 状态(活跃/非活跃) | URL | 操作
  - 操作: 激活 / 更新 / 删除
- 添加订阅表单
  - URL 输入框
  - 名称输入框
  - 确认添加按钮

**交互**:
- 点击「激活」→ 切换该订阅为当前使用
- 点击「更新」→ 重新下载订阅内容
- 点击「删除」→ 确认后删除
- 点击「添加」→ 展开/收起表单

#### 2.3.4 规则管理页

**功能**:
- 当前规则列表 (表格形式)
  - 序号 | 类型 | 值 | 代理 | 操作
  - 操作: 删除
- 添加入口
  - 支持选择规则类型
  - 输入值和代理
- 导入/导出按钮

**交互**:
- 支持分页显示 (每页50条)
- 点击删除 → 移除该规则
- 点击导入 → 选择本地文件

#### 2.3.5 连接监控页

**功能**:
- 实时连接列表 (自动刷新)
  - 序号 | 来源 | 目标 | 代理 | 上行 | 下行 | 持续时间
  - 操作: 断开
- 按连接断开按钮
- 实时流量统计 (顶部)
  - 总上行速率
  - 总下行速率
  - 连接数

**交互**:
- 支持按目标/来源搜索
- 点击断开 → 关闭该连接
- 页面进入时自动开始刷新，离开时停止

#### 2.3.6 设置页

**功能**:
- **常规设置**
  - HTTP 端口 (默认7890)
  - SOCKS5 端口 (默认7891)
  - API 端口 (默认9090)
- **TUN 设置**
  - 启用 TUN 模式 (开关)
  - TUN 堆栈 (system/gvisor)
- **更新管理**
  - Mihomo 版本显示
  - geoip 版本显示
  - 按钮: 检查更新 / 更新全部
- **系统操作**
  - 重启服务
  - 停止服务
  - 重新安装服务

| POST | `/api/service/stop` | 停止服务 |

## 4. 前端技术方案

### 4.1 架构选择

**单文件 HTML 方案**:
- 所有 CSS 和 JavaScript 内联到 HTML 文件
- 通过 `web::get().to(index)` 路由返回
- 使用原生 JavaScript (无框架依赖)
- Fetch API 调用后端

**优势**:
- 零外部依赖
- 部署简单 (单文件)
- 适合嵌入式场景

### 4.2 目录结构

```
src/
├── web.rs          # Actix Web 服务器 + 路由
├── api.rs          # REST API 处理函数
└── html.rs         # HTML 模板 (单文件)
```

### 4.3 HTML 结构

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Control Tower</title>
  <style>
    /* CSS 样式 */
  </style>
</head>
<body>
  <div id="app">
    <!-- 侧边栏 -->
    <nav>...</nav>
    <!-- 主内容 -->
    <main id="main-content">...</main>
  </div>
  <script>
    // JavaScript
  </script>
</body>
</html>
```
